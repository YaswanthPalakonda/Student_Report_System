# Student Report System

A production-style vanilla HTML/CSS/JavaScript student reporting portal using browser `localStorage` only.

## Modules
- Login / Signup / Remember Me / mock password reset
- Protected Admin, Teacher and Student routes
- Admin: dashboard, CRUD users, teacher-class-subject mapping, report review, grading policy
- Teacher: assigned class roster, marks + attendance + remarks, automatic grade/result, report editing
- Student: profile, digital report card, GPA/grade overview, progress bars, print/save PDF
- Light / Dark theme persisted in localStorage
- Responsive CSS Grid/Flexbox layout
